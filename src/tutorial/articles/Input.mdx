# Input

```tsx
import { Input } from '@ui/Input';

<Input
    variant="outlined"
    color="neutral"
    size="small"
    spacing="small"
    mode="text"
    value=""
    placeholder="Enter something"
    disabled={false}
    fullWidth={false}
    // ...
    // any other valid html attributes, applied to the HTMLInputElement
/>;
```

| Property      | Type                                                                                       | Default      | Description                      |
| :------------ | :----------------------------------------------------------------------------------------- | :----------- | :------------------------------- |
| `variant`     | `"solid"` \| `"soft"` \| `"outlined"` \| `"plain"`                                         | `"outlined"` | The variant of the input.        |
| `color`       | `"primary"` \| `"secondary"` \| `"neutral"` \| `"positive"` \| `"warning"` \| `"negative"` | `"neutral"`  | The color of the input.          |
| `size`        | `"small"` \| `"medium"` \| `"large"`                                                       | `"small"`    | The size of the input.           |
| `spacing`     | `"small"` \| `"medium"` \| `"large"`                                                       | `"small"`    | The spacing of the input.        |
| `mode`        | `"text"` \| `"tel"` \| `"url"` \| `"email"` \| `"numeric"` \| `"decimal"` \| `"search"`    | `"text"`     | The mode of the input.           |
| `value`       | `string` \| `number`                                                                       | -            | The value of the input.          |
| `placeholder` | `string` \| `number`                                                                       | -            | The placeholder of the input.    |
| `disabled`    | `boolean`                                                                                  | `false`      | Whether the input is disabled.   |
| `fullWidth`   | `boolean`                                                                                  | `false`      | Whether the input is full width. |
