# Labeled input

```tsx
import { LabeledInput } from '@ui/LabeledInput';

<LabeledInput
    value=""
    label="Label"
    placeholder="Enter something"
    error={false}
    errorLabel="Error"
    // ...
    /
    // any other valid html attributes, applied to the HTMLInputElement
/>;
```

| Property      | Type      | Default | Description                                                         |
| :------------ | :-------- | :------ | :------------------------------------------------------------------ |
| `label`       | `string`  | -       | The label input.                                                    |
| `placeholder` | `string`  | -       | The placeholder of the input, label is used if placeholder ommited. |
| `error`       | `boolean` | `false` | Whether the input has error.                                        |
| `errorLabel`  | `string`  | -       | The friendly error label.                                           |
